tips_and_updates Chrome Web Store Launch Architecture & Guidance
help_outline 1. Should we create 1 page or 10 separate Chrome Store additions?

On the Chrome Web Store, extensions **must be uploaded as separate ZIP listings** (each extension gets its own Store URL, e.g. chromewebstore.google.com/detail/qeloma-shot/...). You cannot bundle multiple popups into a single CRX file.

auto_awesome 2. The Best Strategy: 1 Monorepo → 10 Store ZIPs

Instead of maintaining 10 separate code repos, we build all 10 extensions inside **1 pnpm Monorepo**. Running pnpm build:all outputs 10 individual, lightweight ZIP packages ready to upload directly to your $5 developer account!
